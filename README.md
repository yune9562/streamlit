# 🚇 서울 지하철 이용 패턴 분석

서울교통공사의 **2025년 지하철 이용 데이터를 활용하여 역별·시간대별·호선별·월별 이용 패턴을 분석하고 시각화하는 Streamlit 대시보드**입니다.

## 📌 프로젝트 소개

서울교통공사에서 제공하는 지하철 통행 데이터를 기반으로 다양한 관점에서 서울 지하철 이용 패턴을 확인할 수 있도록 제작했습니다.

Streamlit을 활용하여 별도의 웹 프론트엔드 개발 없이 Python 기반의 데이터 분석 결과를 인터랙티브한 대시보드 형태로 제공합니다.

### 주요 분석 내용

* 🚉 역별 지하철 이용량 분석
* 🕐 시간대별 이용량 분석
* 🚇 호선별 승차·하차 이용량 비교
* 📈 주요 역의 시간대별 이용 패턴 분석
* 💼 출퇴근 시간대 이용량 분석
* 📅 월별 지하철 이용량 변화
* 📋 원본 데이터 확인 및 결측치 확인

## 🚀 실행 방법

### 1. 저장소 Clone

```bash
git clone https://github.com/yune9562/streamlit.git
cd streamlit
```

### 2. 가상환경 및 의존성 설치

`uv`를 사용하는 경우:

```bash
uv sync
```

또는 Python 환경에서 필요한 패키지를 직접 설치할 수 있습니다.

```bash
pip install streamlit pandas matplotlib seaborn koreanize-matplotlib
```

### 3. Streamlit 실행

```bash
streamlit run app.py
```

실행 후 브라우저에서 Streamlit 앱에 접속하면 대시보드를 사용할 수 있습니다.

## ⚡ 데이터 처리 및 성능 최적화

Streamlit은 사용자가 위젯을 조작할 때마다 Python 스크립트를 다시 실행합니다.

따라서 본 프로젝트에서는 `st.cache_data`를 활용하여 데이터 로딩 및 분석 결과를 캐싱합니다.

```python
@st.cache_data(
    show_spinner="🚇 데이터를 분석하는 중..."
)
def load_and_prepare_all_data(...):
    ...
```

또한 CSV 파일의 수정 시간을 캐시 함수의 입력값으로 사용하여 **파일이 변경된 경우에만 데이터를 다시 분석**하도록 구성했습니다.

### 데이터 처리 과정

```text
CSV 파일
   ↓
CSV 인코딩 확인
   ↓
필요한 컬럼만 로딩
   ↓
2025년 데이터 필터링
   ↓
데이터 타입 최적화
   ↓
집계 및 분석
   ↓
Streamlit Cache
   ↓
시각화 및 대시보드 출력
```
